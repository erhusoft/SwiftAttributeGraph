2. ANÁLISIS DE LA RAÍZ DEL COSTE (+14 %) EN shared-proto
--------------------------------------------------------------------------------
Al comparar el código máquina generado en release de HotReadPerformanceTests:
- master: Swiftc inlina value(of:) en el bucle principal de prueba llamando directamente a beginRead(attribute.id).
- shared-proto: value(of:) incluía la comprobación:
    if let primary { return primary.value(of: attribute) }
  Esta recursión/bifurcación polimórfica impidió a LLVM aplanar la llamada inlinable en el bucle del llamador, emitiendo una llamada externa `bl Graph.value(of:)` en cada una de las 10.000.000 de iteraciones.

En microbenchmark aislado:
- Sin recursión / let storage: GraphStorage: inlining completo a nivel de bucle (0 % de regresión).
- Con if let primary: llamada de función externa (+14 % a +15 %).
