=== Tarea 1: Marca +0x58 (Estado: FIRME) ===

1. Medición nativa en sonda (`ProbeNative share-lifetime probe-58`):
   - Configuración: Crear handle s = AGGraphCreateShared(d.graph), leer byte en rawS+0x58, invalidar rawS con c_AGGraphInvalidate, leer byte, volver a invalidar (segunda llamada idempotente), leer byte.
   - Salida medida:
     probe-58|created=0|invalidated=1|doubleInvalidated=1
   - Conclusión medida:
     - Recién creado: byte = 0.
     - Tras primera invalidación: byte = 1.
     - Tras segunda invalidación: byte = 1 (mantiene el valor).

2. Desensamblado en LLDB (AttributeGraph binary en macOS 15.8.3):
   - Creación (AGGraphCreateShared, 0x1c2c4033c):

=== Tarea 2: Fallo de la prueba dos hosts (Estado: FIRME) ===

1. Causa raíz identificada:
   - En la sonda original de two-hosts:
     `let r1: Handle<Int64> = AttributeGraph.Subgraph(graph: s1).apply { Handle(NativeRule(body: { a1.value })) }`
     La instancia de `Subgraph(graph: s1)` se creó de forma temporal sin asignarse a una variable retenida.
   - Swift ARC destruyó el `Subgraph` al terminar la sentencia (`AG::Subgraph::clear_object()`).
   - El destructor del subgrafo desconecta el contexto del nodo de la regla (`[node + 0x28] = 0`).
   - Al invocar `r1.value`, `AGGraphGetValue` cargó el puntero nulo de contexto y llamó a `AG::Graph::value_ref(AG::AttributeID, ...)` con `x0 = 0x0`.
   - La instrucción `ldr w8, [x0, #0x1e0]` desreferenció `0x0 + 0x1e0 = 0x1e0`, provocando `EXC_BAD_ACCESS` (código de salida 139).

2. Corrección y verificación (sonda `two-hosts` con variable retenida):
   - Código:
     ```swift
     let root1 = AttributeGraph.Subgraph(graph: s1)
     let root2 = AttributeGraph.Subgraph(graph: s2)
     let r1: Handle<Int64> = root1.apply { Handle(NativeRule(body: { a1.value })) }
     let r2: Handle<Int64> = root2.apply { Handle(NativeRule(body: { a2.value })) }
     ```
   - Salida medida (`ProbeNative two-hosts`):
     two-hosts|s1ReadsG1=10|s2ReadsG2=20|nodesS1=2|nodesS2=2|nodesG1=2|nodesG2=2
     Exit code: 0 (limpio, 100 % éxito).
   - Lectura cruzada entre grafos independientes (`ProbeNative two-hosts-cross`):
     Exit code: 134 (SIGABRT esperado por violación de espacio de nombres en `AG::Graph::input_value_ref_slow`).
   - Conclusión: El comportamiento nativo del motor es correcto y admite múltiples grafos independientes simultáneamente. El fallo anterior era un error en la sonda por ciclo de vida efímero del Subgraph temporal.
