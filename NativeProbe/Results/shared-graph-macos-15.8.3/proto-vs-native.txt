- Caso I2: i2_independentGraphsCannotReadEachOther
  * Estado: DESHABILITADO (Traps in-process with SIGABRT / exit code 134)
  * Respaldo nativo: NativeProbe/Results/shared-graph-macos-15.8.3/i2-check.txt (10/10 repeticiones abortan con código 134 / SIGABRT y mensaje "precondition failure: accessing attribute in a different namespace: 536").
  * Justificación: En SwiftAttributeGraph, beginRead() valida la condición de aislamiento entre grafos mediante graphTag / primary. Al leer una regla de g2 que accede a un atributo de g1, la precondición falla y aborta el proceso con SIGABRT (exit code 134 / signal 5 en depuración), replicando fielmente el comportamiento de AttributeGraph nativo. Dado que Swift Testing ejecuta las pruebas en el mismo proceso y un aborto termina el proceso de prueba completo, el test se mantiene deshabilitado con la justificación documentada para no interrumpir el resto de la suite.

- Caso Invalidación selectiva: selectiveInvalidation_invalidatingSubgraphFailsOnlyItsRulesWhileOthersRemainReadable
  * Estado: HABILITADO - PASS (0.001s)
  * Respaldo nativo: NativeProbe/Results/shared-graph-macos-15.8.3/subgraph-rule-dependency.txt (SG1 invalidado falla R1; R2 en subgrafo superviviente SG2 completa con éxito devolviendo 12).
  * Resultado en prototipo: la invalidación de sg1 no afecta las reglas creadas bajo sg2, que siguen evaluándose limpiamente a través del handle compartido s.

- Caso Enrutamiento: routing_invalidationNoticeRoutesExclusivelyToHandleWithDependent
  * Estado: HABILITADO - PASS (0.001s)
  * Respaldo nativo: NativeProbe/Results/shared-graph-macos-15.8.3/invalidation-routing.txt (Caso 1B: cadena input -> r -> r2 en S produce cntS=1, cntG=0 tras mutar input desde G) y two-host-routing.txt.
  * Resultado en prototipo: el aviso de invalidación se enruta exclusivamente al contexto del handle que contiene las reglas dependientes (cntS = 1, cntG = 0).
