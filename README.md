# SwiftAttributeGraph

Motor de grafo de atributos en Swift puro, pensado para servir de base a un framework de UI declarativa
(como SwiftUI) en Windows. Solo el motor: sin vistas, layout ni dibujo.

**Estado:** en desarrollo desde cero (versión 0.0.1). El plan y el estado están en
[docs/PLAN-MOTOR.md](docs/PLAN-MOTOR.md); las reglas de trabajo, en [AGENTS.md](AGENTS.md).
Desde el 2026-11-20 `master` es la fuente de verdad del motor (fusión del PR #2); estado, deudas y política de trabajo en
[docs/TRASPASO-2026-11-19.md](docs/TRASPASO-2026-11-19.md) (sección «Actualización 2026-11-20»).

```bash
swift build
swift test
```
